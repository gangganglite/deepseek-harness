# 业务测试计划 · Feature 999 XTerminal SSH

[返回需求简报](../BRIEF.md)

## 范围与依据

Profile 为 simple，采用[项目测试计划模板](../../_templates/TEST_PLAN.tmpl.md)。本次仅规划授权范围内的普通 SSH 任务，覆盖目标查询与选择、路径发现与首次补录、密码与私钥认证、任务接续、审批与多目标执行、输出续读和凭据隔离。插件直连为默认路径，显式指定 `mode: "harness"` 时由 Harness 本机 SSH 执行器使用临时引用建连。两条路径均须交付。本轮增量仅涉及临时连接引用。服务器管理、配置导出及现有远端 Helper 部署在范围之外。

[PRD](../spec/PRD.md#验收条件)维护 AC-1 至 AC-8。[技术方案](../design/TECH_DESIGN.md#远程输出与续读)及[最新复评](../review/design_review.md#最新复评--有条件通过)确认了 AC-7 的交付时序：命令仍在运行且超限文件已可读时提前返回，原会话可以续读，完整文件只在成功写入并关闭后发布。AC-7 仍待 PRD 维护者同步，保留原编号。TC-05 同时列出当前 AC-7 和已确认的时序，供实施后核验。本轮只做静态核对，业务用例均未执行。

TC-06 至 TC-08 沿用 AC-6，按本轮明确的交付范围及[最新技术方案](../design/TECH_DESIGN.md#harness-通过临时引用建连)验收 Harness 模式。

## 待验业务用例

使用隔离 macOS profile、合成 SQLite 库、隔离 SSH 目标和预置可信主机指纹。通过首版实际 `dsh` profile 提交任务，可用录制或模拟模型固定工具批次。各用例保留版本、profile、脱敏结果与必要的隔离服务事件。只运行授权的只读检查或无副作用的测试输出命令，测试完移除临时 profile、合成库和隔离服务。

### TC-01 · 查找服务器并由用户消歧

- 关联需求为 AC-1、AC-2、AC-3、AC-4。
- 准备跨页记录、同名但端点不同的记录、无匹配输入及包含合成哨兵的非公开字段。分别按名称、主机查找，从第一页按返回的分页信息读到末页，并提交一个目标歧义的任务。
- 核对名称、主机、端口及必要分页信息。源库不变时，各页合并与预置记录清单一致。无匹配时提示调整名称或主机，歧义时展示可区分的候选并等待选择，隔离服务在选择前无连接事件。
- 开发测试补齐空表、坏记录、含哨兵的只读查询，以及查询参数不能切换数据源、触发建连或执行命令。业务验收留存脱敏候选列表和连接事件摘要。

### TC-02 · 首次发现、补录与重启复用

- 关联需求为 AC-2、AC-3、AC-5。
- 在不同干净 profile 分别放置唯一可信库和没有可发现库的环境。前者直接请求查询，后者先请求查询，再通过补录入口提交无效候选和有效候选。已配置后提交另一个有效库，重启后查询，再让已保存路径失效。
- 唯一可信库首次使用即保存并继续查询。未配置时提示首次补录，无效候选不写入。有效路径保存后，覆盖请求被拒绝，重启仍读原库，路径失效时提示检查配置。缺失、不可读或损坏反馈不回显底层诊断或原始记录。
- 比对脱敏配置状态、查询结果和源库前后校验值。开发测试补齐不可信路径、链接越出允许目录、发现与并发补录争用时仅一份配置生效。

### TC-03 · 用两种认证方式继续原任务

- 关联需求为 AC-2、AC-4、AC-6。
- 为隔离目标准备密码记录和私钥记录，另准备需要口令的私钥样例。分别交办返回目标预置状态标记的任务，使用默认插件直连，省略单独的连接指令和 Harness 认证配置。再分别模拟凭据不可用或错误、主机指纹未信任或变化。
- 正例按任务选择目标，完成本机认证并返回该目标的标记。主机身份失败在认证前阻止连接，认证失败明确报告阻塞，两类失败均停止依赖该连接的步骤。用不同的预置文本验证普通远端输出可以原样包含用户名。
- 查验模型请求、工具结果与错误、日志、Session 和完整输出文件中没有经认证流程泄漏的合成哨兵或可用连接引用，同时核对源记录保持原样。终态证据仅保留脱敏摘要。

### TC-04 · A 等待审批时 B 独立执行

- 关联需求为 AC-6、AC-8。
- 首版实际 profile 配置至少两个并行槽位，启用可控审批。分别连接 A、B，在同一个真实工具批次提交各自命令。挂起 A 的专项审批，批准 B。通过夹具事件确认 B 已完成且 A 尚未打开命令通道，再批准 A。
- 审批内容包含各自目标和命令。A 只在原连接执行一次，等待本身不使有效调用失效。用远端事件确认执行顺序，批次结束后按调用顺序核对两条工具结果。
- 分别在批准前关闭 A 原连接并建立替代实例、取消 A 调用、拒绝审批或移除审批通道。验证 A 未执行且替代实例未收到命令。单独验证通用前置拒绝有效。若实际 profile 的通用前置等待阻塞 B，记录所用策略及阻塞阶段，AC-8 的同批场景仍待验证通过。
- 留存批次、审批和连接实例对应的脱敏事件。开发测试补齐同目标并发建连、断线后结果未知且不自动重试、跨 turn 拒用和卸载清理。

### TC-05 · 超限时提前返回并在原会话读回全文

- 关联需求为 AC-2、AC-7，含最新复评已确认、待写入 AC-7 的时序。
- 使用预先定义预期全文的 2999、3000、3001 码点输出，包含中文、emoji 和可辨识的两路标准流。另用可控隔离命令先产生超限内容，再等待夹具释放末段，确认工具返回后才让命令完成。增加已结束的超限样例，核对完整文件提示。
- 2999 和 3000 码点结果原样返回。超限响应含提示在内最多 3000 Unicode 码点。运行中的首次响应包含可读路径、作业 ID 和仍在写入提示，记录此时命令仍在运行，完整文件字段为空。
- 在原 Harness 会话读取路径，读到当时 EOF 后查作业状态确认仍在写入。释放末段，等待作业终态，从同一会话读回文件并与预置全文比对。成功写入并关闭后才发布完整文件路径，作业终态应带上该元数据。另验证已批准的作业跨 turn 收尾后原会话仍可读回，旧 turn 的连接入口已收回。
- 验证文件创建失败时提示仍限长且不给路径。提前响应后分别模拟写入失败和取消，核对终态原因和可读片段的不完整标记，完整文件字段保持为空。超时、断线、跨块解码、输出环丢弃，以及按保留期清理已结束文件且保留运行中文件，由开发测试补验。
- 保存初次响应、运行中读回与作业状态、终态及全文比对摘要。凭据隔离同时按 TC-03 核对文件和工具结果。

### TC-06 · Harness 用密码和私钥接续原任务

- 关联需求为 AC-2、AC-4、AC-6。沿用 TC-03 的隔离目标、合成凭据和可信指纹，私钥正例使用可解锁的带口令私钥。Profile 无预配 OpenSSH 别名、远端 Helper 或独立认证材料。
- 分别交办读取目标预置标记的任务，由录制或模拟模型显式调用 `xterminal_connect(mode: "harness")`。审批展示选定目标，获批后由 Host 执行器发起并持有连接。建连结果仅含目标和状态。再批准包含目标和命令的 `xterminal_run`，核对原任务只取回所选目标的标记。以脱敏 Host 事件和隔离目标的认证方式、连接与命令事件对应两次任务。
- 分别拒绝建连审批、移除可用审批通道，核对失败反馈且隔离目标无握手、认证或命令事件。另模拟主机指纹不符、凭据不可用或私钥口令错误，核对对应阻塞，指纹不符时目标无认证事件，各失败均无后续命令和自动重试。修复后显式发起新调用并重新批准，方可继续任务。
- 正例和失败均按 TC-03 核对保密，检查模型请求和工具参数、工具结果与错误、日志、Session 及输出文件。认证哨兵、认证诊断和临时引用均不得出现在这些记录中，源记录保持原样。证据仅保留脱敏摘要。

### TC-07 · 不同目标的两种模式并行，同一目标模式冲突

- 关联需求为 AC-6、AC-8。沿用 TC-04 的实际 profile 和可控审批，A 显式用 Harness 模式，B 省略 `mode` 使用插件直连。分别批准建连，在同一真实工具批次挂起 A 的命令审批，批准 B 的命令。核对 B 已在自己的连接上独立执行且 A 未打开命令通道。批准 A 后仅在 A 原连接执行一次，核对两目标标记和按调用顺序发布的结果。
- 对同一目标分别在建连待定和就绪时发起并批准另一模式的建连，交换先发模式复验。后发调用返回模式冲突，夹具只观察到原尝试，已挂起的尝试可完成，原连接仍可执行获批命令。原连接关闭后，新批准的调用可以选择另一模式。记录脱敏的建连、审批和命令事件。

### TC-08 · 任务退出后撤回入口并释放连接

- 关联需求为 AC-6、AC-8。使用 Harness 模式启动已获批且可由夹具暂停的后台命令。正常结束 turn，下一 turn 直接运行命令时旧入口不可用，夹具无新命令事件。释放已启动作业，按 TC-05 核对其正常收尾及原会话读回，最后一个作业结束后旧连接关闭。下一 turn 可在新批准后重新连接同一目标。
- 分别在待建连接和在途作业阶段销毁 Agent 或卸载插件。观察原任务或作业终止、夹具连接关闭且无迟到的就绪结果，退出完成时待建连接和在途资源均已释放。证据保留脱敏的 turn、退出、作业终态和连接关闭事件。

## 临时引用的开发测试补齐项

- **签发与拒绝。** 用合成目录、可控时钟及认证回调计数，核对拒绝审批、审批渠道缺失和批准前取消均未签发引用。验证引用自签发起计时，签发不读取认证字段。有效引用只把选定记录的凭据交给本机认证回调，Host 用绑定的端点、指纹和剩余期限建连。
- **单次兑付与授权归属。** 分别在首次兑付前和异步目录校验期间触发过期或取消。覆盖串行重放、并发兑付、替换目标、跨批准调用、Agent 实例、Session 或 turn，以及同端点下替换数据库文件或更改记录修订。逐次核对被拒兑付返回固定错误，并且未读取认证字段、调用认证回调或启动 SSH。两个匹配且有效的并发兑付只有一次进入认证。认证失败也消耗引用，重试须重新批准并签发。
- **并发与退出清理。** 覆盖同一目标同一模式复用待建和就绪连接。验证调用结束、turn 结束、Agent 销毁和插件卸载后未消费引用均被撤销。取消或退出与建连成功同时发生时，迟到的连接不登记，启动者关闭并等待资源释放。
- **保密与回放。** 用合成哨兵和可识别的测试引用检查 TC-06 的模型可见及持久化范围，并核对 argv、环境变量、临时文件和 SSH 调试输出。补 keyless snapshot 固定工具入参与可见结果，只保存脱敏证据。
